# Security Policy / Sicherheit

Mage Game ist ein Prototyp in der Planungsphase; es gibt noch keinen Server
und keine veröffentlichten Builds.

## Eine Sicherheitslücke melden

Bitte **nicht** als öffentliches Issue. Stattdessen über GitHub:
*Security → Report a vulnerability* in diesem Repository, oder direkt an die
Maintainer. Wir antworten so schnell wie möglich.

*Please do not open a public issue. Use "Security → Report a vulnerability"
on GitHub instead.*

## Sicherheitsarchitektur

Wie Server und PvP-Kommunikation abgesichert werden (Bedrohungen,
Gegenmaßnahmen, Regeln für jede Änderung), steht im Vault:
[docs/architecture/sicherheit.md](docs/architecture/sicherheit.md).
