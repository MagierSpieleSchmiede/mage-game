# P-001 — Move-and-Slide in Avian 0.8: vorhanden oder Eigenbau? (erledigt)

Erledigt: Avian enthält seit Version 0.6 ein `MoveAndSlide` für kinematische Character Controller, auch in 0.8. Der Magier nutzt es; ein Eigenbau entfällt ([[adr-0003-kinematik-statt-dynamischer-rigidbodies|ADR-0003]]).
