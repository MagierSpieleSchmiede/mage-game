# P-020 — Wann darf die Fähigkeitenleiste geändert werden, und was ist erlaubt?

Die Leiste wird beim Betreten einer Runde oder der Welt geprüft ([[adr-0030-faehigkeitenleiste-vom-spieler|ADR-0030]]). Wann sie geändert werden darf, schlägt [[adr-0032-kampfzustand|ADR-0032]] vor: außer Kampf und im Tod, nie im Kampf. Offen bleibt: Welche Fähigkeiten stehen einem Spieler zur Verfügung (alle, freigeschaltete, je Klasse)? Gibt es Kosten oder Grenzen über die Slot-Zahl hinaus (Punkte-Budget)?

Nächster Schritt: mit dem Spieldesign der Welt entscheiden, spätestens vor M7.
